# Preference Mapper 🎨✨

An Interactive mini web project that maps moods to outfit styling variations.

Live Demo:  
https://dhruvaptl.github.io/Preference-Mapper/

---

## 🌟 Project Idea

Preference Mapper is a styling exploration tool.

Instead of randomly browsing outfits, this project shows how one base outfit can be styled in multiple ways depending on mood, vibe, or occasion.

It focuses on:

- How small accessory changes alter overall vibe
- Visual storytelling through styling
- Clean UI interaction without clutter

---

## 🧠 How It Works (Non-Technical Explanation)

The website:

1. Shows a base outfit.
2. Displays different styling variations.
3. Each variation includes:
   - A vibe description
   - Tags (mood indicators)
   - A small accessory image
4. Clicking any image opens a full-size preview.
5. Users can switch between pages smoothly.
6. Light/Dark mode toggle changes theme.

It is designed to be simple, elegant, and interactive.

## ⚙️ Behind The Scenes (Technical Implementation)

This project demonstrates:

### 1️⃣ Dynamic Rendering
Outfit data is stored inside a JavaScript object.
The content is generated dynamically using DOM manipulation instead of hardcoding HTML.

### 2️⃣ Image Modal System
- Click event detection
- Overlay display handling
- Controlled open/close logic
- Works across desktop & mobile

### 3️⃣ Sliding Page System
- CSS flex-based layout
- Controlled `translateX()` transitions
- Button-controlled navigation

### 4️⃣ Theme Toggle
- Light/Dark mode using class switching
- Smooth transitions

### 5️⃣ Responsive Design
- Media queries for mobile support
- Flexible image sizing
- Layout adjustments for smaller screens

### 6️⃣ Git & Deployment Workflow
- Version-controlled using Git
- Hosted using GitHub Pages
- Debugged deployment-specific issues
- Handled file path and caching differences
